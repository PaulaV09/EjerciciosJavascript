# 📘 Ejercicios de Lógica en JavaScript
### Paula Andrea Viviescas Jaimes

Este proyecto contiene una serie de retos de programación resueltos en **JavaScript**, enfocados en el uso de estructuras básicas como arreglos, cadenas, pilas, sets y objetos.

Los ejercicios están diseñados para practicar **pensamiento lógico** y el manejo de funciones en JS, con entradas a través de `prompt` y salidas usando `alert`.

------

## 📂 Ejercicios incluidos

1. **🔮 Hechizo codificado**
   - Decodificar un mensaje mágico representado con símbolos.
2. **📂 Archivos comprometidos**
   - Determinar qué archivos fueron modificados después de la última descarga segura.
3. **✍️ Frases plagiadas**
   - Detectar frases copiadas comparando contra una base de datos sospechosa.
4. **🍎 Frutas envasadas**
   - Verificar si una secuencia de frutas respeta el orden de apilado (LIFO).
5. **👩‍💻 Habilidades compatibles**
   - Comparar habilidades de candidatos contra una oferta laboral y encontrar a los compatibles (≥70%).
6. **🌀 Puertas del portal temporal**
   - Encontrar el primer carácter único en una secuencia de portales.
7. **🔤 Anagramas**
   - Determinar si dos palabras son anagramas (ignorar mayúsculas/minúsculas).

------

## 🚀 Tecnologías usadas

- **JavaScript** (ES6)
- **HTML** 

------

## 📝 Cómo ejecutar

1. Clona o descarga el proyecto.
2. Abre el archivo `index.html`.
3. Vincula cada ejercicio con un `<script src="ejercicioX.js"></script>`.
4. Abre el archivo en el navegador.
5. Interactúa con los **prompts** y mira los resultados en **alerts**.
